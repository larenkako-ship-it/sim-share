================================================================
  كيفاش تخرج ملف APK مجاناً من GitHub فدقيقتين (بلا Android Studio)
================================================================

1. افتح حسابك فـ https://github.com (أو أنشئ حساب مجاني).
2. اضغط على + الفوق -> New repository -> سمّيه مثلاً sim-instant-share -> Create repository.
3. فك الضغط على هاد الـ ZIP فالبيسي، وارفع جميع الملفات والمجلدات (بما فيها مجلد .github) للـ repository.
   (ملاحظة: باش ترفع مجلد .github المخفي بسهولة، استعمل GitHub Desktop أو git push).
4. دخل لتبويب Actions الفوق فـ GitHub -> غتلقى Build SIM Instant Share APK خدام بوحدو!
5. بعد ~2 دقائق غيولي أخضر ✅ -> اضغط عليه وهبط لتحت لـ Artifacts -> حمل SIM-Instant-Share-APK.
6. صيفط ملف app-debug.apk لتليفونك عبر LocalSend وأنستاليه!
7. افتح التطبيق فالتيليفون، كتب رابط البيسي (مثلاً http://10.16.132.88:8765)، ضغط "اتصال"،
   ووجه الكاميرا لبطاقة SIM — كيقرا النمرة فـ 0.2 ثانية ويصيفطها نيشان للبيسي ويكوبيها فـ Ctrl+V!
================================================================
